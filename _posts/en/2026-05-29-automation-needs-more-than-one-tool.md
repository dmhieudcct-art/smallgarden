Many people start their automation journey with a favorite tool — then try to force every problem into it. The result is usually an overly complex solution that's hard to maintain and prone to breaking.

The truth is that every tool has its own strength zone. Knowing when to use what — and how to combine them — is the core skill.

VBA — the Office weapon
Strong in Excel/Word, no installation needed, runs right inside the file. Downsides: old syntax, can't run outside the Office environment, hard to debug when logic gets complex.

Python — flexible and powerful
Handles complex data, connects to APIs, reads files in any format. Requires setting up an environment and knowing how to code, but in return there are no real limits.

Power Automate Desktop (PAD) — UI automation
When there's no API and no access to raw data — PAD records mouse and keyboard actions. Great for legacy software and internal systems with no integrations.

n8n — connecting services
When the problem is "when X happens, do Y at Z" — n8n is the right tool. Drag-and-drop workflows, connects hundreds of services, self-hostable. Doesn't replace Python but complements it perfectly.

The right strategy: use the lightest tool that can solve the problem. When the problem grows, combine tools. Never try to use a hammer to tighten a screw.
